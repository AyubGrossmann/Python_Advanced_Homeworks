Организация проекта

Каждое домашнее задание находится в отдельной папке.

Каждая папка содержит собственные файлы Django-проекта, файл "requirements.txt" и файл "README.md" с инструкциями.

Установка и запуск

1. Склонируйте репозиторий.
2. Откройте папку нужного домашнего задания.
3. Создайте и активируйте виртуальное окружение.
4. Установите зависимости:

pip install -r requirements.txt

5. Следуйте инструкциям в соответствующем файле README.md.
