# Домашнее задание 11 — Inline формы и Admin actions

Проект продолжает ДЗ №8, №9 и №10. Используются те же модели Task, SubTask и
Category. Поля моделей и миграции предыдущих заданий сохранены.

## Что реализовано

### Задание 1. Inline форма

В `TaskAdmin` подключён `SubTaskInline`:

```python
inlines = [SubTaskInline]
```

Теперь при создании или редактировании задачи можно сразу добавить подзадачу
в блоке под основной формой.

### Задание 2. Короткие названия задач в списке

В `TaskAdmin` используется метод `short_title()`:

```python
@admin.display(description="Название задачи", ordering="title")
def short_title(self, obj):
    if len(obj.title) > 10:
        return obj.title[:10] + "..."
    return obj.title
```

В таблице списка задач длинное название сокращается до первых 10 символов
и многоточия. Само поле `title` и метод `__str__()` модели не меняются,
поэтому при выборе задачи в поле связи подзадачи показывается полное название.

### Задание 3. Admin action для подзадач

Добавлено действие `mark_subtasks_as_done`. В списке подзадач нужно отметить
галочками нужные записи, выбрать действие «Отметить выбранные подзадачи как
Done» и нажать «Выполнить». Статус выбранных подзадач изменится на `Done`.

## Как запустить

Откройте корневую папку `DjangoHomework8_TaskManager` в PyCharm.

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте админку:

http://127.0.0.1:8000/admin/

## Как проверить задания

1. Откройте Tasks → Add task. Убедитесь, что внизу формы есть блок SubTasks,
   где можно сразу добавить подзадачу.
2. Создайте задачу с длинным названием. В общем списке Tasks должно отображаться
   только 10 первых символов и `...`. Откройте задачу и убедитесь, что полное
   название сохранилось.
3. Откройте SubTasks. Отметьте несколько подзадач, в выпадающем списке Actions
   выберите «Отметить выбранные подзадачи как Done» и нажмите Go/Выполнить.
   Проверьте, что статус изменился на Done.


Модели не изменялись, поэтому новая миграция для ДЗ №11 не нужна.
