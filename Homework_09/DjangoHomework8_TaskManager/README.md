# Homework 9 — Task Manager (продолжение Homework 8)

Этот проект создан на основе вашего архива ДЗ №8. Существующие поля, связи,
статусы и настройки Django Admin сохранены. Добавлены только изменения,
которые требуются в ДЗ №9.

## Что сделано в ДЗ №9

1. В моделях `Task`, `SubTask` и `Category` есть метод `__str__()`.
2. В `Meta` добавлены имена таблиц:
   - `task_manager_task`
   - `task_manager_subtask`
   - `task_manager_category`
3. Для `Task` и `SubTask` сохранена сортировка по убыванию `created_at`.
4. Добавлены человекочитаемые имена моделей: `Task`, `SubTask`, `Category`.
5. Уникальность:
   - `Task.title` — уже была в ДЗ №8;
   - `Category.name` — уже была в ДЗ №8;
   - `SubTask.title` — добавлена в ДЗ №9.
6. Настройки Django Admin из ДЗ №8 сохранены: список полей, фильтры,
   поиск, просмотр даты создания и добавление подзадач внутри задачи.
7. Добавлена миграция `0002_homework9_meta_and_unique.py`.

## Установка и запуск

Откройте корневую папку `DjangoHomework8_TaskManager` в PyCharm.

Создайте виртуальное окружение (если его ещё нет):

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Примените миграции:

```bash
python manage.py migrate
```

Создайте администратора:

```bash
python manage.py createsuperuser
```

Запустите сервер:

```bash
python manage.py runserver
```

Откройте админку: http://127.0.0.1:8000/admin/

Создайте несколько записей Category, Task и SubTask. У каждой подзадачи
выберите основную задачу. Для скриншотов откройте списки каждой из трёх
моделей в админке.


## Важно

Миграция `0002` предполагает, что миграция ДЗ №8 `0001_initial` уже применена.
Если вы запускаете проект впервые на пустой базе, команда `migrate` выполнит
обе миграции по порядку.

Если в базе уже есть две подзадачи с одинаковым `title`, перед применением
миграции нужно переименовать дубликаты, потому что теперь название подзадачи
должно быть уникальным.
