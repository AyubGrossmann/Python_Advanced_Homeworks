# Домашнее задание 14 — параметры запросов и пагинация

Проект продолжает Task Manager из ДЗ №8–13. Предыдущие модели, сериализаторы,
представления и маршруты сохранены. В ДЗ №14 добавлены фильтрация по дню недели,
пагинация подзадач и фильтры по названию основной задачи и статусу подзадачи.

## Задание 1. Список задач по дню недели

Endpoint:

`GET http://127.0.0.1:8000/api/tasks/`

- Без параметров — возвращает все задачи.
- С параметром `weekday` — возвращает задачи, у которых дедлайн приходится
  на указанный день недели.

Примеры:

```text
/api/tasks/
/api/tasks/?weekday=вторник
/api/tasks/?weekday=Monday
/api/tasks/?weekday=пятница
```

Поддерживаются русские и английские названия дней недели.

## Задание 2. Пагинация списка подзадач

Endpoint:

`GET http://127.0.0.1:8000/api/subtasks/`

На одной странице показывается максимум 5 подзадач.
Сначала отображаются последние созданные подзадачи.

Примеры:

```text
/api/subtasks/
/api/subtasks/?page=1
/api/subtasks/?page=2
```

В ответе DRF будут поля `count`, `next`, `previous` и `results`.

## Задание 3. Фильтрация списка подзадач

Endpoint:

`GET http://127.0.0.1:8000/api/subtasks/`

Можно использовать два query-параметра:

- `task_title` — название основной задачи (поиск без учёта регистра и по части названия);
- `status` — статус подзадачи.

Примеры:

```text
/api/subtasks/?task_title=Prepare
/api/subtasks/?status=New
/api/subtasks/?task_title=Prepare&status=New
/api/subtasks/?task_title=Prepare&status=Done&page=2
```

Если фильтры не переданы, возвращается весь список с пагинацией.
Если передан один фильтр, применяется только он. Если переданы оба — оба
условия применяются одновременно.

## Как запустить в PyCharm

Откройте папку `DjangoHomework8_TaskManager`.

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Новые миграции не нужны: модели не менялись.

## Что изменено в коде

Основная логика находится в `tasks/views.py`:

- `TaskListCreateAPIView.get_queryset()` — фильтрация задач по `weekday`;
- `SubTaskPagination` — ограничение 5 записей на страницу;
- `SubTaskListCreateView.get_queryset()` — фильтрация по `task_title` и `status`;
- `order_by("-created_at")` — сортировка от новых подзадач к старым.


## Примечание

Фильтр `weekday` проверяет день недели поля `deadline`.
Если у задачи нет дедлайна (`deadline = NULL`), она не попадёт в выборку
по конкретному дню недели, но будет отображаться в общем списке без фильтра.
